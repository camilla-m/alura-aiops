## 🧩 Habilidades desenvolvidas

- Utilizar IA para reconstruir timelines de falhas e gerar runbooks
- Mapear tendências invisíveis e causas raízes recorrentes com agrupamento estatístico
- Configurar agrupamento automático de logs para isolar exceções
- Detectar quebras de sequência lógica em padrões de logs
- Alimentar ferramentas de IA com logs reais para inferir causas-raiz
