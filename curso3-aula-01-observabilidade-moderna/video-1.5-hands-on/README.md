# Vídeo 1.5 — Hands-on: Investigando comportamento operacional com múltiplos sinais

## 🎬 Roteiro

**Tipo:** Demonstrar Solução (Hands-on)  
**Habilidade:** Executar cenários práticos de rastreamento e correlação de sinais múltiplos para isolar bugs em laboratório.

### Desenvolvimento

- **Prática:** Laboratório guiado usando múltiplos sinais para debugar um microsserviço com falha técnica profunda

---

## 💡 O que você vai praticar

1. Receber sinais heterogêneos (métricas, logs, traces, eventos de deploy)
2. Correlacionar sinais usando trace_id e proximidade temporal
3. Identificar a causa raiz usando contexto operacional
4. Gerar um relatório de investigação completo
5. Propor ações de mitigação e prevenção
