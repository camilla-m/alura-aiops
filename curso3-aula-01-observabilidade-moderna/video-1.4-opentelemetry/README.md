## 💡 Conceitos-chave

- **OpenTelemetry (OTel):** Especificação aberta para instrumentação, coleta e exportação de telemetria
- **OTel Collector:** Agente que recebe, processa e exporta dados de telemetria
- **APIs e SDKs:** Interfaces de programação para instrumentação manual e automática
- **OTLP:** OpenTelemetry Protocol — formato padronizado de transporte
- **Vendor-agnostic:** Independência de fornecedor para exportação de dados
