# Aula 3 — Alertas inteligentes e redução de ruído

## 🎯 Objetivo de aprendizagem

Implementar estratégias avançadas de baselines dinâmicos e alertas contextuais para erradicar a fadiga de alarmes e o ruído em times SRE.

## 🧩 Habilidades desenvolvidas

- Avaliar criticamente limites fixos tradicionais e por que falham em microsserviços dinâmicos
- Configurar baselines dinâmicos baseados em histórico real
- Desenhar estratégias de depuração de alertas excessivos
- Construir alertas complexos com dependências de topologia
- Configurar monitores com limites inteligentes para reduzir ruído operacional
